## Layout

```text
.
├── flake.nix          # Inputs, host definitions, and formatter
├── Makefile           # Common rebuild, update, and format commands
├── assets/
│   ├── screenshots/
│   └── wallpapers/    # GNOME light/dark PNGs and macOS dynamic HEIC
├── hosts/             # Machine-specific configurations
│   ├── energy/        # NixOS desktop (GNOME + gaming)
│   ├── xps/           # NixOS laptop (GNOME)
│   └── work-mac.nix   # macOS work laptop (AeroSpace)
└── modules/
    ├── common/        # Shared Nix settings, user.name option, and HM wiring
    ├── nixos/         # NixOS baseline, GNOME desktop + session, and opt-in gaming
    ├── darwin/        # macOS baseline, system preferences, keyboard, and AeroSpace
    └── home/          # Cross-platform Home Manager modules, Neovim, and scripts
```

## Conventions

- `flake.nix` wires each host directly via `nixpkgs.lib.nixosSystem` or `nix-darwin.lib.darwinSystem`.
- Settings live in the module that uses them; there is no shared preferences layer. The only custom option is `user.name` (declared in `modules/common/base.nix`, set per host).
- Directory boundaries follow platform scope strictly: `modules/common/` is shared system setup, `modules/nixos/` is NixOS-only (including GNOME's Home Manager session in `modules/nixos/gnome/session.nix`), `modules/darwin/` is macOS-only, and `modules/home/` is shared across all machines.
- Baseline workstation features live in `modules/nixos/base.nix`, `modules/darwin/base.nix`, and `modules/home/base.nix`. Opt-in features such as `modules/nixos/gaming.nix` are imported explicitly by the hosts that use them.
- Hardware support is plain NixOS options in each host's `hardware.nix` (generated by `nixos-generate-config`, plus GPU extras); there is no `nixos-hardware` input.
- Timezone and regional formats are owned by the desktop, as on macOS: set the timezone in GNOME Settings (or `timedatectl set-timezone`). The GNOME Formats region is set in `modules/nixos/gnome/session.nix` and compiled into glibc via `i18n.extraLocales` in `modules/nixos/gnome/default.nix`.
- Terminal colors are defined once in `modules/home/alacritty.nix`; CLI/TUI tools (`tmux`, `fzf`, `starship`, `lazygit`, `btop`, `k9s`, `opencode`) inherit the terminal's ANSI palette directly.

## How to use this repo for yourself

### 1. Fork and clone

Fork this repository and clone the fork.

### 2. Replace personal settings

Personal values live where they are used:

- Git name, email, and signing key: [`modules/home/git.nix`](modules/home/git.nix)
- Terminal font package, family, and size: [`modules/home/alacritty.nix`](modules/home/alacritty.nix)
- Keyboard layouts and regional formats: [`modules/nixos/gnome/session.nix`](modules/nixos/gnome/session.nix) and [`modules/nixos/gnome/default.nix`](modules/nixos/gnome/default.nix)
- Username: `user.name` in each file under `hosts/` (and the NixOS user description in [`modules/nixos/base.nix`](modules/nixos/base.nix))

Replace the wallpaper files with your own:

- `assets/wallpapers/wallpaper-light.png`
- `assets/wallpapers/wallpaper-dark.png`
- `assets/wallpapers/wallpaper-mac.heic`

The PNGs are applied automatically in GNOME; the HEIC contains matching light/dark variants for manual selection in macOS.

### 3. Trim or replace hosts

Update or remove hosts under `hosts/` and their entries in `flake.nix`.

### 4. Add a host

For NixOS:

```sh
mkdir -p hosts/laptop
sudo nixos-generate-config --show-hardware-config > hosts/laptop/hardware.nix
```

`hosts/laptop/default.nix`:

```nix
{
  imports = [
    ./hardware.nix
    ../../modules/nixos/base.nix
  ];

  networking.hostName = "laptop";
  user.name = "your-user";
  system.stateVersion = "26.05";
}
```

Register it under `nixosConfigurations` in `flake.nix`:

```nix
laptop = inputs.nixpkgs.lib.nixosSystem {
  specialArgs = { inherit inputs; };
  modules = [ ./hosts/laptop ];
};
```

For macOS, copy `hosts/work-mac.nix`, set `user.name` to your macOS login short name, and register the machine's short hostname under `darwinConfigurations` in `flake.nix`.

Remember to `git add` any new files before building.

### 5. Build

```sh
make nixos-rebuild     # NixOS
make darwin-rebuild    # macOS
make fmt               # format the repository
```

`make help` lists all targets. The `Makefile` defaults to `.#$(hostname -s)`, so flake outputs named after the machine's short hostname are selected automatically.

## Adding modules

- A new cross-platform Home Manager module lives in `modules/home/<name>.nix` and is imported in `modules/home/base.nix` (small CLI additions go directly into `modules/home/packages.nix` or `modules/home/shell.nix`).
- A new NixOS or macOS system feature lives in `modules/nixos/<name>.nix` or `modules/darwin/<name>.nix`; put baseline defaults in the matching `base.nix` and import opt-in features in the relevant `hosts/` files.
